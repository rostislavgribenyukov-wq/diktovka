# Диктовка

Русский голосовой ввод в любое окно. Зажимаете клавишу — говорите — отпускаете — готовый текст вставляется под курсор.

Распознавание идёт полностью локально (ничего не уходит в облако):
- **macOS** — Whisper через MLX на чипах Apple Silicon (быстро, в 2–3 раза быстрее длительности речи)
- **Windows** — faster-whisper, на видеокартах NVIDIA через CUDA, без неё — на процессоре

## Как пользоваться

| | macOS | Windows |
|---|---|---|
| Клавиша | правый ⌘ (Command) | F8 |
| Действие | зажать → говорить → отпустить | нажать F8 → говорить → нажать F8 ещё раз |

Пока идёт запись, внизу экрана видна стеклянная плашка: красная точка-пульс, уровень громкости голоса. Значок микрофона — в меню-баре (Mac) или возле часов (Windows). Клик по значку — запись вкл/выкл, настройки, журнал, выход.

Настройки лежат в `config.json` рядом с программой: клавиша, модель, звуки, автоотправка Enter.

## Установка

### macOS

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/rostislavgribenyukov-wq/diktovka/main/install_mac.sh)"
```

Скрипт сам поставит Python, библиотеки и модель, создаст приложение «Диктовка» и включит автозапуск. После установки зайдите в **Системные настройки → Конфиденциальность и безопасность** и разрешите «Диктовке»: Микрофон и Универсальный доступ (без этого программа не сможет ни услышать, ни вставить текст).

### Windows

В PowerShell (обычном, не обязательно администратор):

```powershell
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/rostislavgribenyukov-wq/diktovka/main/install.ps1 | iex"
```

Программа появится на рабочем столе и в автозапуске. Удаление: `C:\Diktovka\uninstall.ps1`.

## Обновления

Программа раз в несколько часов сама проверяет версию в этом репозитории и, если вышла новая, скачивает её и перезапускается. Ничего нажимать не нужно — на всех компьютерах обновления приходят сами.

## Файлы

- `diktovka.py` — вся программа (один файл, macOS + Windows)
- `VERSION` — текущая версия (по ней идёт автообновление)
- `install_mac.sh`, `install.ps1`, `uninstall.ps1` — установщики
